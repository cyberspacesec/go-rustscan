# go-rustscan 技术文档

## 1. 项目概述

### 1.1 项目背景

go-rustscan 是一个基于 Go 语言开发的高性能端口扫描工具，它是对 RustScan 的封装和增强。该项目旨在提供一个更加易用、功能丰富的端口扫描解决方案，同时保持 RustScan 的高性能特性。通过提供 HTTP API 和命令行两种使用方式，满足不同场景下的端口扫描需求。

### 1.2 主要特性

- **双模式支持**：同时支持 HTTP API 和命令行两种使用方式
- **高性能扫描**：继承 RustScan 的快速扫描能力
- **任务队列管理**：内置任务队列，支持高并发控制
- **结果持久化**：支持扫描历史记录和结果的持久化存储
- **资源管理**：内置速率限制和资源管理机制
- **异步通知**：支持 webhook 方式的结果异步通知
- **AI 集成**：支持 MCP 协议，可与各类 AI 助手无缝集成

## 2. 系统架构

### 2.1 整体架构

go-rustscan 采用模块化的架构设计，主要包含以下核心组件：

- **CLI 模块**：负责命令行交互和参数解析
- **API 服务**：提供 HTTP API 接口
- **扫描引擎**：封装 RustScan 核心功能
- **任务队列**：管理扫描任务的调度和执行
- **存储模块**：处理结果持久化
- **通知模块**：负责异步事件通知

### 2.2 核心模块说明

#### 2.2.1 CLI 模块

CLI 模块位于 `cmd/cli` 目录下，主要包含：

- `root.go`：根命令定义
- `scan.go`：扫描相关命令
- `serve.go`：HTTP 服务相关命令

#### 2.2.2 API 服务模块

API 服务模块位于 `pkg/api` 目录下，提供以下功能：

- REST API 接口
- 批量扫描支持
- MCP 协议集成
- Webhook 通知

#### 2.2.3 RustScan 集成模块

位于 `pkg/rustscan` 目录，负责：

- Docker 容器管理
- 结果格式转换
- 类型定义

## 3. 核心功能实现

### 3.1 端口扫描

#### 3.1.1 基本扫描流程

1. 参数解析和验证
2. 创建扫描任务
3. 调用 RustScan 执行扫描
4. 结果解析和存储
5. 通知（可选）

#### 3.1.2 示例代码

```go
// 基本扫描示例
func basicScan() {
    scanner := rustscan.NewScanner()
    result, err := scanner.Scan("example.com", "80,443")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Printf("Scan result: %+v\n", result)
}
```

### 3.2 批量扫描

#### 3.2.1 批量扫描特性

- 支持多目标并发扫描
- 任务队列管理
- 失败重试机制
- 进度追踪

#### 3.2.2 示例代码

```go
// 批量扫描示例
func batchScan() {
    targets := []string{"example1.com", "example2.com"}
    ports := "1-1000"
    
    batch := scanner.NewBatchScanner()
    results, err := batch.ScanMultiple(targets, ports)
    if err != nil {
        log.Fatal(err)
    }
    
    for target, result := range results {
        fmt.Printf("Target: %s, Result: %+v\n", target, result)
    }
}
```

### 3.3 HTTP API

#### 3.3.1 API 端点

- `POST /api/v1/scan`：执行单个扫描任务
- `POST /api/v1/batch/scan`：执行批量扫描任务
- `GET /api/v1/scan/:id`：查询扫描结果
- `GET /api/v1/scan/:id/status`：查询扫描状态

#### 3.3.2 API 示例

```bash
# 单个扫描请求
curl -X POST http://localhost:8080/api/v1/scan \
  -H "Content-Type: application/json" \
  -d '{
    "target": "example.com",
    "ports": "80,443",
    "rate_limit": 1000,
    "timeout": 5
  }'

# 批量扫描请求
curl -X POST http://localhost:8080/api/v1/batch/scan \
  -H "Content-Type: application/json" \
  -d '{
    "targets": ["example1.com", "example2.com"],
    "ports": "1-1000",
    "concurrent": 5
  }'
```
